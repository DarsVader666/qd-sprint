| 1 | 段错误，无提示 | `root()` 访问空/过小的 vector | `g++ -g -fsanitize=address` | 用 `resize(n+1)` | C 实现 |

| 5 | 输出粘在一起 `21 3` | `cout << cnt;` 后面缺 `'\n'` | `cat -A` 看行尾 | 补换行或直接输出 `res.size()` | C 实现 |
| 6 | 断点没触发，程序直接跑完 | 断点打在了不执行的分支，或被 `-O2` 优化掉 | 看断点是否变灰（不可达） | 用 `-O0 -g3` 编译，断点打在实际执行的行 | E 调试 |
| 7 | 程序一直卡着不结束 | `while(cin>>x)` 在终端里没给 EOF | 看是否停在等待输入 | 输入后按 `Ctrl+D`，或用 `< in.txt` 重定向 | E 调试 |
| 8 | 二分死循环或答案不对 | `mid = (l+r)/2` 写到了 `while` 外面，`mid` 永不更新 | 在循环体里打 logpoint 看 `mid` 是否变化 | `mid` 必须写在循环体内 | C 实现 |
| 9 | 二分 `check` 少算一个 | `check` 忘了先把计数器减一（第一个球/第一份已占用） | 手推 m=2 的最小用例 | 进 `check` 先处理第一个，再循环 | C 实现 |
| 10 | 换了当前元素，比较长度没同步 | `cur=nxt` 之后 `cur_size` 仍是旧值 | 拿长度可变的数据测（a / bz / by） | 每次换 cur 就重算 cur_size | C 实现 |
| 11 | RE（段错误），小数据全过 | 数组开死 `10005`，但 `n` 上限更大 | ASan 报的行号落在 `cin >> a[i]` | 按 `n` 动态开 `vector` | C 实现 |

| 19 | 控制块被提前释放 → `heap-use-after-free` | `weak_cnt` 随 shared 计数同步增减，第一个对象析构就把它减到 0 | ASan 定位到 `use_count()` 读已释放内存 | `weak_cnt = 1 + weak_ptr 数`，**不随 shared 析构减少**；强计数归零时才 `--weak_cnt` | C 实现 |
