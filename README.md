# QD C++ 冲刺：90 天，稳定做出 L3 难度的题

> **目标**：给一道**没见过的**、和技能黑白棋同难度的题（CF 1700–1800 / 面试 Hard），
> **75 分钟内独立做出**，并且能讲清复杂度、边界和测试方案。
>
> 黑白棋不再是主线，而是**可选 capstone**：它是一道很好的「规则建模 + 搜索」综合题，
> 但九坤不一定考。真正要练的是**可迁移的 8 个题型族**。

## 先看这四句话

1. **975 分是两场样本，噪声极大**。它只说明前两场低于初始 1500，既不能证明你 1900，也不能证明你只有 975。用「75 分钟冷解」校准，别用 rating 定义自己。
2. **「做过黑白棋」≠「会做同类题」**。面试/笔试换一道网格 BFS、状压 DP 或博弈题，你照样要能拆。所以主线是 8 个族 + 每周 2 道冷解。
3. **稳定 = 冷解率，不是学习量**。L3 的及格线：最近 10 道没见过的 1700–1800，≥7 道在 75 分钟内做出；达不到就回炉，不要赶进度。
4. **通勤 8 小时是输入时间，不是输出时间**。地铁上做「看、背、推演、口述」，键盘时间做「写、调、测」。

## 90 天一眼图

```
W1-4   F1 模拟 → F2 网格搜索 → F3 二分 → F4 前缀/差分
W5-8   F5 DP → F6 状压 → F7 博弈 → F8 图论
W9-10  弱项回炉 + 混合冷解 + 手撕 + 八股
W11    3 场 75 分钟 mock + 2 场虚拟赛
W12    Held-out 20 题（≥13/20）+ 最终复盘
```

每周固定：**2 道冷解 + 1 场虚拟赛 + 1 次手撕 + 1 次错题重做**。
黑白棋（可选）只占 W6–W8 的每周 3–4 小时，**不挤掉冷解**。

四个硬里程碑：

| 里程碑 | 验收 | 时间 |
|---|---|---|
| **G1** | 3 道 1400–1500，≥2 道 75min | W2 末 |
| **G2** | 4 道 1500–1600，≥3 道 75min | W4 末 |
| **G3** | 4 道 1700–1800，≥3 道 75min | W8 末 |
| **G4** | Held-out 20 题 ≥13/20 | W12 末 |

> G2 是分水岭。W4 还做不到 1500 的 3/4，就不要进状压/博弈，先把 F1–F4 打穿。

1. 做 [`02_plan90.md`](02_plan90.md) 开头的「开营自测」10 题，判断要不要加 3 天语法。

4. 在 [`worksheets/log.md`](worksheets/log.md) 建好冷解记录表；今天只做 1 道 1400 的题热身，别刷一整天。

## 我做的三个假设（不对就改计划）

- **A1**：你每周能拿出 **30 小时左右**有键盘的时间。只有 15–18 小时，看 [`02_plan90.md`](02_plan90.md) 的压缩版。
- **A2**：3 个月后是**笔试 + 面试**，不是明天。如果只剩 4 周，用第 11 节的 4 周版。
- **A3**：你在地铁上**不能稳定写代码**（最多手机/平板看和记）。有笔记本+座位的话，[`03_commute.md`](03_commute.md) 末尾有「能写代码版」。
